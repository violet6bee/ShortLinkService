1. Как пользоваться сервисом.
   * Пользоваться приложением можно с помощью консольной строки вводя специальные команды, описанные ниже.

2. Какие команды поддерживаются:
   * create user - создать пользователя
   * insert link - вставить ссылку для сокращение
   * go to - перейти по короткой ссылке
   * edit limit - редактировать лимит
   * delete link - удалить ссылку
   
3. Как протестировать код.
   * Создать пользователя командой "create user"
   * Вставить ссылку для сокращение командой "insert link"
   * Ввести UUID пользователя
   * Ввести количество лимитов на переход по ссылке
   * Получить короткую ссылку
   * При желании можно ввести команду edit limit, после ввести UUID пользователя, затем ввести новый лимит
   * При желании можно удалить ссылку командой delete link, после ввести UUID пользователя.
